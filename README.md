# 九九乘法口诀消消乐

一个基于 Web 的九九乘法口诀消消乐游戏。

## 游戏规则

- 选择三个连续的数字（横、竖或L型）
- 如果它们能组成一句乘法口诀（a×b=c，其中a和b是1-9，c是积），即可标记
- 找到所有符合条件的组合即可获胜！
- 游戏板上保证有4-10个有效组合

## 如何运行

直接在浏览器中打开 `index.html` 即可开始游戏。

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)
